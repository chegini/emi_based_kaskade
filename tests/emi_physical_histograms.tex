\section*{Pepe physical histograms: compression onset at time step \onset}
@@SOLVER@@, 16-bit transform-first compression, constant splitting on.
Each onset is a separate run; time step 6 follows five uncompressed steps.
The first observed restriction/prolongation call is retained per producer.
These plots show physical values, not the unsigned quantization indices.

The input is already weighted and, for prolongation, centered by constant
splitting. The coefficient is the floating input to quantization. Each direction
uses a single common scale $M$, the largest absolute value across its input and
coefficient populations. Shared packet copies are counted; exact corners are
excluded. All observations enter 64 equal-width bins. Lines connect bin centres.

\def\kind{signed}
\panel{restrict}{Restriction: signed}{-1}{$y/M$}\hfill

\def\kind{magnitude}

A concentration near zero indicates small coefficients. It does not establish
which basis functions have low or high spatial frequency. Absolute scales,
population counts and source hashes are recorded in \texttt{summary.json}.
The capture must pass exact observer-off/on solution, solver-trace and byte-count
checks before these plotting tables are exported. These are diagnostic runs,
not performance measurements.
